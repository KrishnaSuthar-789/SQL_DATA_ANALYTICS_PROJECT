# SQL_Exploratary_Data_Analysis_Project

**A collection of SQL scripts use for data exploration.**
The scripts use various analysis techniques to: 
  - Explore the measures and dimension
  - Analysing the ranging and magnitude
  - Aggregate the data
  - Change over time
  - Track YoY trend/change
  - Track monthly trend
  - Perform Cumulative Analysis
  - Performance Analysis
And much more !

## Table/data used in this project is loaded from the ETL Warehouse Project.
Check it out here : https://github.com/KrishnaSuthar-789/SQL_DATA_Warehouse_Project
